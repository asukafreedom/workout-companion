Redesign · Workout Companion

Athletic, high-contrast, progress-first

Assumptions: same three-tab structure, same data model and plan — only the presentation changes. Type: Barlow Condensed for titles and numbers (the data becomes the hero), Barlow for text. Color: one energetic accent (orange) for "the thing to do next", green only for done, charcoal neutrals. Motivation: a weekly consistency strip, a session progress bar, PR/“best” callouts and deltas on every chart — all computed from data the app already stores. Dark is the default; light shown for Today and the logger. Compare with the current UI.

Turn 2 · Animated form viewer

The viewer becomes a looping rep. Each exercise has two phases (eccentric / concentric) with their own duration, so the scrubber is a phase timeline, not a plain progress bar. The primary muscles pulse in time with the concentric phase; the current form cue changes with the phase. Striped areas are where the rigged figure (three.js AnimationMixer) renders — the ghost dumbbell path shows the motion the model would follow.
