Animated form viewer

This is the exact runtime the app will use — a bone hierarchy driven by AnimationMixer.clipAction('incline-db-press'), named muscle materials that pulse on the concentric phase, and the phase scrubber from the mock. The figure is a code-built stand-in; the real rigged écorché from Blender drops in via GLTFLoader with zero UI changes. Drag to orbit, pinch/scroll to zoom.

What runs here
  • Bone hierarchy upperArm_L/R → forearm_L/R → hand_L/R; clip = QuaternionKeyframeTracks per bone, 3 s loop, keys sampled with ease-in-out per phase.
  • Hand roll solved per keyframe so the dumbbell handle stays horizontal — the same trick you'll want as an IK/constraint in Blender.
  • Muscle materials named pec_major, deltoid_anterior, triceps; emissiveIntensity driven by action.time so the pulse is locked to the concentric phase.
  • Hand path is sampled from the rig, not hand-drawn — it will be correct for any clip.
Asset pipeline (Blender, one-time)
  1. Start from the Z-Anatomy rigged écorché (CC-BY-SA 4.0). Decimate to ≤ 40k tris; keep muscle groups as separate materials named exactly as muscleMap.ts keys.
  2. Per exercise: get a clip — Mixamo for bodyweight moves, phone mocap (Rokoko Video / Move One) for machine and cable lifts. Retarget with Rokoko Studio or Auto-Rig Pro onto the écorché armature.
  3. Trim each clip to one rep, mark the eccentric/concentric split, loop-clean the first/last frame. Name the action after Exercise.id.
  4. Export one figure.glb with all actions (Draco compressed, ~3–6 MB), precache in the service worker.
Code changes for Claude Code

  • Highlight: iterate gltf.scene materials, match names against exercise.primary/secondary, set emissive; pulse from action.time / tempo.
